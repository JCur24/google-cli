Google CLI privacy policy

Last updated: October 7, 2026

What it accesses

Google CLI accesses only the Google account data that a signed-in user explicitly grants on Google's consent screen, such as Gmail messages, and only for that user's own account.

How the data is used

Data is used solely to perform the actions the signed-in user runs from the tool on the developer's own computer. It is not sold, shared, transferred to third parties, used for advertising, or used to train models.

Storage

Sign-in tokens are stored encrypted on that computer. No data is sent to any server other than Google's APIs.

Revoking access

Any user can revoke access at any time at myaccount.google.com/permissions.

Limited Use

Google CLI's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions can be sent to the user support email shown on Google's sign-in screen for this app.
